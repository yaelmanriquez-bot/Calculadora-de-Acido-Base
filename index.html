Ácido fuerte

Un ácido fuerte se disocia completamente: [H⁺] = Cácido. Ej: HCl, HNO₃, H₂SO₄.

Ácido débil

Un ácido débil se disocia parcialmente. Se usa su constante Ka: Ka = x² / (C−x). Ej: CH₃COOH.

Base fuerte

Una base fuerte se disocia completamente: [OH⁻] = Cbase. Ej: NaOH, KOH.

Base débil

Una base débil se disocia parcialmente. Se usa su constante Kb: Kb = x² / (C−x). Ej: NH₃.

Desde pH o pOH conocido

Si ya conoces el pH o el pOH de una solución, obtén el resto de las variables: [H⁺] = 10⁻pH, [OH⁻] = 10⁻pOH.

    Tres modelos de alcance creciente

    Arrhenius (1887)

    Basada en la disociación iónica en agua.

    Ácido: libera H+ (o H3O+).

    HCl(ac) → H+(ac) + Cl−(ac)

    Base: libera OH−.

    NaOH(ac) → Na+(ac) + OH−(ac)

    Limitación: solo disoluciones acuosas; no explica el NH3, que no tiene grupos OH.

    Lewis

    Ácido: acepta un par de electrones (tiene orbitales vacíos). Base: aporta un par de electrones no compartido.

    BF3 + :NH3 → F3B–NH3

    El BF3 (hibridación sp2) tiene un orbital p vacío: es el ácido. El NH3 aporta el par libre: es la base.

    Brønsted-Lowry: transferencia de protones

    Ácido: cede un protón (H+). Base: capta un protón. Toda reacción forma dos pares conjugados.

    Ácido débil

    HNO2 + H2O ⇌ NO2− + H3O+
    HNO2 ácido→NO2− base conjugada
    H2O base→H3O+ ácido conjugado

    Base débil

    NH3 + H2O ⇌ NH4+ + OH−
    NH3 base→NH4+ ácido conjugado
    H2O ácido→OH− base conjugada

    Según los protones que pueden ceder

    • Monopróticos: HCl, HNO3, HCOOH (fórmico), CH3COOH (acético), C6H5COOH (benzoico).
    • Dipróticos (en dos etapas): H2SO4, H2S, H2CO3.
      H2SO4 → H+ + HSO4−  |  HSO4− ⇌ H+ + SO42−
    • Tripróticos: H3PO4.
      H3PO4 ⇌ H+ + H2PO4− ⇌ H+ + HPO42− ⇌ H+ + PO43−

    Ventaja: funciona fuera del agua y explica la basicidad del NH3. Desventaja: el ácido debe tener al menos un hidrógeno.

    Autoprotólisis del agua

    El agua es anfiprótica: puede actuar como ácido o como base. En agua pura ocurre:

    H2O(l) + H2O(l) ⇌ H3O+(ac) + OH−(ac)
    Kw = [H3O+]·[OH−] = 1,0×10−14  (25 °C)

    En agua pura (neutra): [H3O+] = [OH−] = 1,0×10−7 M.

    pH y pOH

    Søren Sørensen propuso la escala logarítmica de acidez:

    pH = −log[H+]    pOH = −log[OH−]    pH + pOH = 14
    [H+] = 10−pH    [OH−] = 10−pOH
    • pH < 7: ácida ([H+] > 10−7 M).
    • pH = 7: neutra.
    • pH > 7: básica o alcalina ([OH−] > 10−7 M).

    ¿Qué hay en cada solución?

    Ácida (pH < 7)
    más H⁺ que OH⁻
    Neutra (pH = 7)
    H⁺ = OH⁻
    Básica (pH > 7)
    más OH⁻ que H⁺

    La fuerza depende del grado de disociación

    Ácido fuerte: 10 de 10 se separan

    Ácido débil: solo 1 de 10 se separa

    Fuertes (100 % disociados, →)

    Ácidos: HCl, HNO3, H2SO4, HClO4.

    [H+] = [Ácido]

    Bases: NaOH, KOH, LiOH, Ca(OH)2.

    [OH−] = [Base]  (o 2×[Base] si libera dos OH−)

    Débiles (parciales, ⇌)

    HB + H2O ⇌ H3O+ + B−
    Ka = [H3O+][B−] / [HB]
    [H+] ≈ √(Ka·[Ácido])
    B + H2O ⇌ BH+ + OH−
    Kb = [OH−][BH+] / [B]
    [OH−] ≈ √(Kb·[Base])

    Cuanto mayor es Ka (o Kb), más fuerte es el ácido (o la base). La raíz cuadrada es una aproximación válida si se disocia poco; la calculadora resuelve la ecuación cuadrática exacta x² + K·x − K·C = 0.

    Algoritmo de cálculo en 3 pasos

    1. Identifica el electrolito: ¿es ácido o base? ¿fuerte o débil?
    2. Calcula la concentración iónica: ácido fuerte [H+] = [Ácido]; base fuerte [OH−] = [Base] (× n.º de OH−); ácido débil [H+] = √(Ka·C); base débil [OH−] = √(Kb·C).
    3. Convierte a escala logarítmica: si tienes [H+]: pH = −log[H+]. Si tienes [OH−]: pOH = −log[OH−] y pH = 14 − pOH.

    Ejemplos resueltos

    Seis ejercicios paso a paso. Usa el botón de cada uno para verlo en la calculadora. (Los ejemplos 4 a 6 usan la aproximación √(K·C); la calculadora resuelve la ecuación exacta, así que el pH puede diferir en ±0,01.)

    Ejemplo 1 · pH de un ácido fuerte

    Problema: Calcule el pH de una disolución 0,04 M de ácido perclórico (HClO4).

    1. Ácido fuerte, disociación total: HClO4 → H+ + ClO4−.
    2. [H+] = 0,04 M.
    3. pH = −log(0,04) = 1,40.

    Resultado: pH = 1,40

    Ejemplo 2 · Base fuerte monohidroxilada

    Problema: Calcule el pH de una disolución 0,028 M de KOH.

    1. KOH → K+ + OH− (disociación total).
    2. [OH−] = 0,028 M.
    3. pOH = −log(0,028) = 1,55.
    4. pH = 14 − 1,55 = 12,45.

    Resultado: pOH = 1,55 · pH = 12,45

    Ejemplo 3 · Base fuerte dihidroxilada

    Problema: Calcule el pH de una disolución 0,0011 M de Ca(OH)2.

    1. Ca(OH)2 → Ca2+ + 2 OH−.
    2. [OH−] = 2 × 0,0011 = 0,0022 M.
    3. pOH = −log(0,0022) = 2,66.
    4. pH = 14 − 2,66 = 11,34.

    Resultado: pH = 11,34

    Ejemplo 4 · Hallar Ka desde la concentración y el pH

    Problema: Una disolución 0,10 M de ácido fórmico (HCOOH) tiene pH 2,38. Calcule Ka.

    1. [H+] = 10−2,38 = 4,17×10−3 M.
    2. Ka = [H+]² / [Ácido].
    3. Ka = (4,17×10−3)² / 0,10 = 1,74×10−5 / 0,10 = 1,74×10−4.

    Resultado: Ka = 1,74×10−4

    Ejemplo 5 · Ácido débil con Ka conocida

    Problema: Calcule el pH de CH3COOH 0,30 M, con Ka = 1,8×10−5.

    1. [H+] = √(Ka·C).
    2. [H+] = √(1,8×10−5 · 0,30) = √(5,4×10−6) = 2,32×10−3 M.
    3. pH = −log(2,32×10−3) = 2,63.

    Resultado: pH = 2,63

    Ejemplo 6 · Base débil con Kb conocida

    Problema: Calcule pH y pOH de metilamina (CH3NH2) 0,26 M, con Kb = 4,4×10−4.

    1. [OH−] = √(Kb·C).
    2. [OH−] = √(4,4×10−4 · 0,26) = √(1,144×10−4) = 0,0107 M.
    3. pOH = −log(0,0107) = 1,97.
    4. pH = 14 − 1,97 = 12,03.

    Resultado: pOH = 1,97 · pH = 12,03
